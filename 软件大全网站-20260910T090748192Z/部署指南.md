# 《软件大全》网站 · 零成本部署指南

> 面向编程新手的完整操作手册。跟着做，全程不花一分钱。

---

## 一、先搞清楚：为什么需要三个平台

你用的 DigitalPlat **只提供域名**，它不存网站文件、也没有数据库。所以完整方案是三家分工，各自都有免费额度：

| 平台 | 负责什么 | 免费额度 | 是否必需 |
|---|---|---|---|
| **Supabase** | 存软件数据、存上传的文件、管注册登录 | 数据库 500MB / 文件 1GB / 流量每月 5GB | 必需 |
| **Cloudflare Pages** | 存放并对外提供你的网页 | 静态站点免费、流量不限 | 必需 |
| **DigitalPlat** | 给你一个像 `ruanjian.dpdns.org` 的专属网址 | 1 个免费域名 | 可选（不做也能用） |

**为什么 DigitalPlat 可选**：Cloudflare 部署完会自动给你一个 `你的名字.pages.dev` 网址，网站立刻就能用、能分享给别人。绑定自己的域名只是让网址更好看。建议先跳过第四步，等网站跑通了再回来做。

```
访客浏览器
    │
    ├─→ Cloudflare Pages   拿到网页文件（HTML/CSS/JS）
    │
    └─→ Supabase           读软件列表、注册登录、下载文件
```

网页是静态的，但**数据存在 Supabase 云端**，所以任何人打开网站看到的都是同一份软件列表 —— 这正是你要的「每个人都能发布、每个人都能下载」。

## 二、第一步：注册 Supabase 并建数据库

### 2.1 注册

1. 打开 <https://supabase.com>，点右上角 **Sign In**
2. 用 **GitHub 账号**登录最省事（没有的话去 <https://github.com> 注册一个，两分钟）
3. 首次登录会让你创建一个 **Organization**（组织），随便起个名，Plan 选 **Free**

### 2.2 创建项目

1. 点 **New Project**
2. 填写：
   - **Name**：`ruanjian-daquan`（或你喜欢的英文名）
   - **Database Password**：设一个强密码，**记在记事本里存好**（网站本身用不到它，但你日后维护需要）
   - **Region**：选 **Southeast Asia (Singapore)**，国内访问最快
3. 点 **Create new project**，等 1～2 分钟初始化

### 2.3 执行建库脚本

1. 左侧菜单点 **SQL Editor**（图标像个小终端）
2. 点 **New query**
3. 用记事本打开本目录里的 `数据库建库SQL.sql`，**全选复制**，粘贴到编辑器里
4. 点右下角 **Run**（或按 `Ctrl + Enter`）
5. 看到 **Success. No rows returned** 就成功了

> 这个脚本会一次性建好：软件数据表、用户资料表、数据库权限规则、文件存储桶、下载计数功能、删除自动清理文件。
> 脚本可以重复执行，跑多次不会出错、也不会重复建表。

**这段脚本里最关键的是权限规则**，它决定了安全边界：

- 任何人（包括未登录访客）都能**看**软件列表、都能下载
- 只有登录用户能**发布**，且只能以自己的身份发布
- 每个人**只能删除和修改自己发布的**条目，动不了别人的
- 未登录者**无法上传文件**

这些规则由数据库强制执行，不是靠网页代码「装样子」。就算有人改浏览器代码绕过前端，数据库也会拒绝。

### 2.4 关闭邮箱验证（重要，别跳过）

不关的话，用户注册完必须去邮箱点确认链接才能登录，很多人会卡在这一步以为网站坏了。

1. 左侧 **Authentication** → **Sign In / Up**（或 **Providers → Email**）
2. 找到 **Confirm email**，把开关**关掉**
3. 点 **Save changes**

### 2.5 记下两个网址信息

1. 左侧 **Project Settings**（齿轮图标）→ **API Keys**（旧版叫 **API**）
2. 记下这两项：
   - **Project URL**，形如 `https://abcdefghijk.supabase.co`
   - **anon public** 密钥，一长串字符

> ⚠️ **千万不要复制 `service_role` 密钥。** 那个是管理员万能钥匙，泄露出去任何人都能删光你的数据。只能用 **anon public**，它是设计给网页前端用的公开密钥，权限已被上面那些规则严格限制。

## 三、第二步：把网址填进网站代码

1. 用**记事本**打开交付给你的网站文件（单文件版 HTML）
2. 按 `Ctrl + F` 搜索 `在这里粘贴你的网址`
3. 把两处占位符替换成你自己的信息：

```javascript
window.APP_CONFIG = {
  SUPABASE_URL: 'https://hjlgailxkktdwrfjmftl.supabase.co/rest/v1/',   // ← 换成你的 Project URL
  SUPABASE_ANON_KEY: 'eyJhbGciOiJIUzI1NiIsInR5cCI...', // ← 换成你的 anon public 密钥
  STORAGE_BUCKET: 'software-files',                   // ← 不要改
  MAX_UPLOAD_MB: 50                                   // ← 不要改
};
```

4. 保存（注意别把引号和逗号删掉）

> 替换后**保留引号**，结尾的逗号也不能少，否则整个网页会白屏。

## 四、第三步：部署到 Cloudflare Pages

### 4.1 注册

打开 <https://dash.cloudflare.com/sign-up>，邮箱注册即可，**不需要绑信用卡**。

### 4.2 上传网站

1. 左侧菜单点 **Workers & Pages**
2. 点 **Create**（创建应用程序）→ 选 **Pages** 标签
3. 选择 **Upload assets**（直接上传 / Drag and drop your files）
4. 项目名填 `ruanjian`（只能用英文、数字、短横线）
5. **把文件拖进上传框**：
   - 如果你用的是**单文件版**：先把文件**重命名为 `index.html`**，再拖进去
   - 如果你用的是**源码版**（`软件大全.html` + `assets` 文件夹）：把 `软件大全.html` **重命名为 `index.html`**，然后把它和 `assets` 文件夹**一起**拖进去
6. 点 **Deploy site**，等约 30 秒

> 🔴 **必须改名为 `index.html`**。Cloudflare Pages 规定网站根目录必须有一个叫这个名字的文件作为首页，否则打开网址会显示 404。这是新手最常卡住的一步。

### 4.3 测试

部署完成后，Cloudflare 会给你一个网址，形如：

```
https://ruanjian.pages.dev
```

打开它。这时**不要急着高兴**，按下面四项逐一验证：

| 验证项 | 操作 | 预期结果 |
|---|---|---|
| 数据库连通 | 打开网址 | 看到软件库页面，**不是**「网站还没连接数据库」的提示页 |
| 注册功能 | 点「登录后可发布」→ 切到「注册」→ 填昵称邮箱密码 | 提示注册成功，右上角显示你的昵称 |
| 发布功能 | 点「发布软件」→ 填完信息 → 发布 | 提示成功，新条目出现在列表最前面 |
| 下载功能 | 点刚发布条目的「下载」 | 链接方式会新开标签页；上传方式会开始下载 |

### 4.4 把网址加入 Supabase 白名单

回到 Supabase → **Authentication** → **URL Configuration**：

- **Site URL** 填 `https://ruanjian.pages.dev`
- **Redirect URLs** 里也加一条同样的地址，点 **Save**

不做这一步，注册登录有可能因为跨域被拦下来。

## 五、第四步：绑定 DigitalPlat 免费域名（可选）

> 做完这步，网址会从 `ruanjian.pages.dev` 变成 `ruanjian.dpdns.org` 这种你自己的名字。
> 网站已经能用了，这步纯粹为了好看和好记，可以以后再做。

### 5.1 注册 Cloudflare 拿到 NS 地址

（如果你已经用 Cloudflare 部署了网站，账号已经有了，直接用）

1. Cloudflare 首页点 **+ Add a domain**（添加站点）
2. 这里**先不要填**，因为你还不知道要填什么域名 —— 先去 DigitalPlat 想好名字
3. 想好后回来填，比如 `ruanjian.dpdns.org`
4. 套餐选 **Free**（0 美元）
5. Cloudflare 会给你**两个名称服务器地址**，形如：
   ```
   xxx.ns.cloudflare.com
   yyy.ns.cloudflare.com
   ```
   **把这两个地址复制下来**，下一步要用

### 5.2 在 DigitalPlat 注册域名

1. 打开 <https://dash.domain.digitalplat.org>，用邮箱注册并验证
2. 登录后点右上角 **Connect GitHub**，授权你的 GitHub 账号（这一步是为了防滥用，必须做）
3. 左侧点 **Register**
4. 填你想要的名字，选后缀 `.dpdns.org`
5. 在 **Nameservers** 里粘贴上面那两个 Cloudflare 地址
6. 点 **Register!**

### 5.3 等待生效

回到 Cloudflare，刷新页面，状态会从 Pending 变成 **Active**。

> ⏳ **这一步需要耐心**。域名信息要同步到全球根服务器，通常 12～24 小时，快的话几十分钟。期间网址打不开是正常的，不用反复折腾。

### 5.4 把域名接到网站上

Cloudflare 状态变成 Active 之后：

1. Cloudflare → **Workers & Pages** → 点你的项目
2. **Custom domains** 标签 → **Set up a custom domain**
3. 填入 `ruanjian.dpdns.org` → 确认
4. Cloudflare 自动签发免费 HTTPS 证书，几分钟后就能用新网址访问

### 5.5 记得更新 Supabase 白名单

绑定新域名后，回到 Supabase → **Authentication** → **URL Configuration**，把 **Site URL** 改成新域名，并在 **Redirect URLs** 里加上新域名。否则在新网址上注册登录会失败。

### 5.6 关于续期（必须知道）

DigitalPlat 的免费域名**不是永久的，需要定期续期**，过期不续会被回收，网站就打不开了。

> ⚠️ 关于续期周期，公开资料存在**不一致说法**：有来源称「每 180 天续订一次」，也有来源称「2026 年 1 月 1 日起新注册域名改为按年续期，到期前 180 天开放免费续期通道」。
>
> **请以你 DigitalPlat 后台 Domains 页面显示的实际到期日为准**，不要依赖任何一篇教程的说法。建议现在就打开后台看一眼到期日，并在手机日历里设一个提前 30 天的提醒。

## 六、必须知道的四个限制（都是真金白银的坑）

### 6.1 流量额度只有每月 5GB —— 这是最容易爆的

Supabase 免费版**每月只给 5GB 出站流量**。用户通过「直接上传文件」方式下载软件，**每一次下载都消耗你的流量额度**。

举例：一个 50MB 的软件被下载 100 次 = 5GB，**当月额度直接用完**，之后网站就读不出数据了。

**应对办法（强烈建议）**：

- 引导大家**优先用「粘贴下载链接」方式**发布 —— 文件放在夸克网盘、蓝奏云、GitHub Release 上，下载不消耗你的额度，而且**没有大小限制**
- 站内上传只留给小工具、绿色版小软件
- 我在发布界面已经写了这个引导提示

### 6.2 项目闲置 7 天会被自动暂停

Supabase 免费项目如果**连续 7 天没有任何活动**，会被自动暂停，网站会打不开（显示连接失败）。

**应对办法**：每几天自己打开一次网站，有任何读写活动就会重置这个计时器。或者网上有 GitHub Actions 定时脚本方案，但对你来说**手动打开最省事**。

如果真的被暂停了：登录 Supabase 后台，会看到 **Restore project** 按钮，点一下等几分钟就恢复，**数据不会丢**。

### 6.3 存储只有 1GB

站内上传的所有文件加起来不能超过 1GB。我在 SQL 里已经写了自动清理：删除条目时会同步删掉对应的文件，不会留垃圾占空间。

如果快满了，去 Supabase → **Storage** 能看到占用明细，清理掉没人下载的大文件。

### 6.4 没有内容审核机制 —— 这是法律风险，不只是技术问题

**你选的是「注册后即可发布」，本站没有审核、举报、下架功能。** 这意味着：

- 任何人都能上传任何文件，包括病毒、破解软件、侵权软件、违法内容
- 作为站点提供者，你可能要为这些内容承担责任
- DigitalPlat 的服务条款明确禁止用其域名分发恶意软件，违规会导致**域名被回收**
- Cloudflare 同样会因滥用投诉封停你的项目

**我强烈建议你至少做一件事**：定期（比如每周）打开网站，浏览一遍新发布的条目，发现违规内容就用你自己的账号在 Supabase 后台删掉。

如果日后想加「发布后需管理员审核才显示」「举报按钮」这类功能，告诉我，我可以给你加上。

## 七、常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面显示「网站还没连接数据库」 | 第三步的网址或密钥没填、没保存 | 重新检查 `window.APP_CONFIG`，确认引号和逗号完整 |
| 网页整个白屏 | 填配置时误删了引号或逗号 | 按 `F12` 看 Console 报错，通常是 `SyntaxError`，补回符号 |
| 提示「数据表还没建好」 | SQL 脚本没执行或执行失败 | 回 SQL Editor 重新 Run 一次（可重复执行） |
| 注册时提示「邮箱已注册」 | 这个邮箱真注册过了 | 直接切到「登录」标签登录 |
| 注册后要求去邮箱验证 | 第 2.4 步没关邮箱验证 | 关掉 Confirm email；已注册的用户需去邮箱点链接 |
| 登录提示「邮箱或密码不正确」 | 密码记错了 | 本站没有自助找回密码。你用管理员身份在 Supabase → Authentication → Users 里能删掉该用户让他重新注册 |
| 上传文件报错 | 文件超过 50MB，或存储桶没建好 | 改用「粘贴下载链接」；或回 SQL Editor 重跑脚本 |
| 下载站内文件没反应 | 存储桶没设为公开 | 重跑 SQL 脚本（里面会把桶设为 public） |
| `pages.dev` 能开，自定义域名打不开 | 域名还没全球生效 | 等 12～24 小时，见 5.3 |
| 网站突然全部连不上 | Supabase 项目被闲置暂停 | 登录后台点 Restore project |

## 八、日后想改东西怎么办

| 想改什么 | 改哪里 |
|---|---|
| 分类名称（现在有 9 个） | 网站文件里搜 `var CATS`，改数组内容。注意：**数据库里已发布的旧条目仍会显示原分类** |
| 平台选项 | 搜 `var PLATS` |
| 上传大小上限 | 搜 `MAX_UPLOAD_MB`，但**免费版硬上限就是 50MB**，改大了也没用 |
| 配色、字体 | 网站文件里搜 `SECTION: variables`，改 `--acc`（主色）等变量 |
| 每页显示几个软件 | 搜 `var PAGE_SIZE`，默认 12 |
| 网站标题、首页文案 | 网页里搜「人人都能发布」 |

改完之后，回 Cloudflare → 你的项目 → **Deployments** → **Upload new version**，重新拖一次文件就更新了，网址不变。

## 九、文件清单

| 文件 | 用途 |
|---|---|
| `软件大全.html` | 网站源码主文件（HTML + CSS），本地双击可打开 |
| `assets/app.js` | 网站核心逻辑（连接数据库、发布、下载、登录），**部署时必须和 HTML 一起上传** |
| `数据库建库SQL.sql` | 粘贴到 Supabase SQL Editor 执行的建库脚本 |
| `部署指南.md` | 本文件 |
| `history/` 里的单文件版 | 把 JS 内联进了 HTML 的整合版，部署时只需上传这一个文件（改名为 `index.html`） |

**源码版 vs 单文件版怎么选**：

- **想以后自己改代码** → 用源码版（`软件大全.html` + `assets/app.js`），改 JS 逻辑方便
- **只想赶紧上线，不想管文件夹** → 用单文件版，改名 `index.html` 直接上传

两个版本功能完全一样，选哪个都行。
